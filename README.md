# 🎨 ระบบหอเกียรติยศและบันทึกคะแนนเก็บตามชิ้นงานวิชาศิลปะ (Art Classroom Management System)

เว็บแอปพลิเคชันสำหรับบันทึกคะแนนเก็บตามชิ้นงานที่สั่งในห้องเรียนศิลปะ จัดอันดับคะแนนสะสม และบริหารจัดการห้องเรียนสำหรับนักเรียนระดับประถมศึกษา (ป.1 - ป.6) ออกแบบด้วย **HTML5, CSS3 และ JavaScript** พร้อม Favicon ไอคอนจานสี **🎨**, โพเดียม 3 มิติ, แอนิเมชันสาดสี และระบบจัดการชิ้นงาน/ห้องเรียน นำเข้า-ส่งออก Excel/CSV ครบวงจร

---

## 🌟 ฟังก์ชันและฟีเจอร์เด่นของระบบ

### 1. 📝 ระบบคะแนนเก็บตามงานที่สั่ง (Assignment-based Scoring)
- **ปรับเปลี่ยนจากเกณฑ์แบบตายตัว มาเป็นระบบตามชิ้นงานที่ครูสั่งจริงในห้องเรียน**:
  - เช่น *งานที่ 1: การไล่เฉดสีน้ำ (เต็ม 25)*, *งานที่ 2: วาดภาพสัตว์ในจินตนาการ (เต็ม 25)*, *งานที่ 3: ภาพพิมพ์และคอลลาจ (เต็ม 25)*, *งานที่ 4: การแรเงาเส้น (เต็ม 25)* ฯลฯ
- **เพิ่ม / ลด / แก้ไขหัวข้องานได้อิสระ (Dynamic Assignments Manager)**:
  - คุณครูสามารถกดปุ่ม **"📝 จัดการหัวข้องาน"** เพื่อเพิ่มชิ้นงานใหม่ กำหนดชื่อชิ้นงาน และระบุคะแนนเต็มของแต่ละงานได้เอง (เช่น งานละ 10, 20, 25, 30 หรือตามต้องการ)
  - เมื่อเพิ่มหรือลบชิ้นงาน ระบบจะเพิ่ม/ลดคอลัมน์ในตารางกรอกคะแนน และปรับการคำนวณคะแนนเต็มรวม (Total Max Score) ให้อัตโนมัติทันที
- **ตัดส่วนที่ไม่จำเป็นออกตามที่แจ้ง**: ไม่ต้องกรอกชื่อผลงานหรืออัปโหลดรูปภาพ เน้นที่ชื่อนักเรียน คะแนนตามชิ้นงาน และคำติชมของคุณครู

---

### 2. 🔍 นักเรียนทุกคนกดดูรายละเอียดคะแนนของตัวเองได้ (Student Portfolio Modal)
- คลิกที่ **ชื่อนักเรียน** หรือปุ่ม **"🔍 ดูคะแนน"** ในตาราง หรือคลิกที่การ์ดของ 3 อันดับแรกบนโพเดียม
- แสดงหน้าต่างสรุปคะแนนส่วนตัว:
  - ชื่อ-นามสกุล, ชื่อเล่น, เลขที่, ระดับชั้น และห้องเรียน
  - อันดับปัจจุบัน (Rank) และฉายาทางศิลปะ (เช่น 👑 แปรงทองคำ, 🌟 จิตรกรเอก)
  - รายการแจกแจงคะแนนของ **แต่ละชิ้นงานที่สั่ง** พร้อมแถบเปอร์เซ็นต์ความก้าวหน้า และสถานะ (✓ ส่งแล้ว / ⏳ ยังไม่ส่ง)
  - คะแนนรวมสุทธิเทียบกับคะแนนเต็ม และเกรดผลการเรียน (A+, A, B+, B, C, D)
  - การเปรียบเทียบสถิติ: เทียบคะแนนตนเองกับ **คะแนนเฉลี่ยทั้งห้อง** และ **คะแนนสูงสุดประจำห้อง**
  - กล่องแสดง **คำชื่นชมและคำแนะนำส่วนตัวจากคุณครู**

---

### 3. 👩‍🏫 ห้องพักครูกรอกและจัดการคะแนนได้ง่ายและครบวงจร (Teacher Portal)
- **กรอกคะแนนสะดวกรวดเร็ว (Inline Realtime Editing)**: พิมพ์คะแนนลงในช่องของแต่ละงานได้ทันที ระบบจะ Auto-save ลงในเบราว์เซอร์อัตโนมัติ และอัปเดตคะแนนรวมพร้อมโพเดียมแบบ Real-time
- **จัดการห้องเรียน (Room Config)**: เพิ่มห้องเรียนใหม่ (เช่น ป.4 ห้อง 4) หรือลบห้องที่ไม่ต้องการ เชื่อมโยง Dropdown ทั้งระบบอัตโนมัติ
- **นำเข้าไฟล์ Excel (.xlsx) และ CSV (Bulk Import)**:
  - มีปุ่มดาวน์โหลดไฟล์ตัวอย่าง **Template (.csv)** ที่สร้างหัวตารางตรงตามชิ้นงานปัจจุบันให้ทันที
  - ลากไฟล์มาวาง (**Drag & Drop**) และมีหน้าจอตรวจสอบตัวอย่าง (**Preview**) ก่อนกดยืนยัน
- **ส่งออกคะแนนเป็นไฟล์ Excel (.xlsx) และ CSV (Export)**:
  - รองรับการส่งออกเฉพาะห้องปัจจุบัน หรือส่งออกรวมทุกห้องทุกชั้นเรียน
  - เข้ารหัสภาษาไทย **UTF-8 BOM** เปิดใน Microsoft Excel ได้ทันทีโดยภาษาไทยไม่เพี้ยน

### 4. 👑 โพเดียม 3 มิติ และ แอนิเมชันลูกเล่นธีมศิลปะ
- เข้าเว็บมาเริ่มต้นที่ **ชั้นประถมศึกษาปีที่ 4 ห้อง 1 (ป.4/1)** เป็นค่าเริ่มต้น
- โพเดียม 3 อันดับแรกสุดอลังการ (อันดับ 1 ทองคำสูงสุดตรงกลาง, อันดับ 2 เงิน, อันดับ 3 ทองแดง) แสดงจำนวนงานที่ส่งครบและคะแนนรวม
- ลูกเล่นแอนิเมชันสาดสีพาสเทลลอยในพื้นหลัง
- แอนิเมชันจุดพลุกระดาษสี (Confetti Canvas)
- ระบบเสียงเอฟเฟกต์สังเคราะห์ (Web Audio API) ปลอดภัย ใช้งานออฟไลน์ได้ 100% พร้อมปุ่มเปิด/ปิดเสียง 🔊

## 🔐 ระบบความปลอดภัยและการยืนยันตัวตน (Authentication & Accounts)

1. **ระบบ Login เข้าห้องพักครู**:
   - หน้าแรก (ทำเนียบนักเรียน) ไม่แสดงเกรด โดยจะแสดงอันดับ คะแนนรวม และฉายาทางศิลปะอย่างสร้างสรรค์
   - เมื่อต้องการเข้าสู่ **"ห้องพักครู (จัดการระบบ)"** ระบบจะตรวจสอบ Session หากยังไม่ได้ Login จะมีหน้าต่างยืนยันตัวตน
   - **ความปลอดภัยระดับสูง**: **ไม่มีการเขียนรหัสผ่านแบบ Plain-text ไว้ในโค้ดหรือหน้าเว็บ** แต่ใช้การเข้ารหัสทางเดียว **SHA-256 Cryptographic Hash** ผ่าน Web Crypto API
   - *ค่าเริ่มต้นสำหรับการเข้าใช้งานครั้งแรก*:
     - **Username**: `admin`
     - **Password**: `admin1234`
2. **ระบบเพิ่มบัญชีครู (Add Teacher Accounts)**:
   - คุณครูที่เข้าสู่ระบบแล้ว สามารถกดปุ่ม **"👥 เพิ่ม / จัดการ Account"** เพื่อสร้าง Username, ชื่อที่แสดง และรหัสผ่านให้กับคุณครูท่านอื่นได้
   - ระบบจะเข้ารหัสรหัสผ่านด้วย SHA-256 และบันทึกไว้ในระบบฐานข้อมูลอย่างปลอดภัย
   - มีปุ่ม **"🚪 ออกจากระบบ"** เพื่อตัด Session ทันทีเมื่อเลิกใช้งาน

## ☁️ คำแนะนำ: หาก Deploy ขึ้น Vercel ควรสร้าง Database ไว้ที่ไหนดี?

หากต้องการนำเว็บไซต์นี้ขึ้น **Vercel** เพื่อให้นักเรียนและคุณครูเปิดใช้งานผ่านลิงก์ออนไลน์ได้จริง มีคำแนะนำด้านฐานข้อมูลดังนี้ครับ:

### 1. ถ้ายังต้องการใช้งานแบบง่ายที่สุด (Client-side / ออฟไลน์ในห้องเรียน)
- ปัจจุบันเว็บไซต์เขียนด้วย **HTML5 / CSS / Vanilla JS** ที่บันทึกข้อมูลผ่าน `localStorage` ในเครื่อง
- **สามารถ Deploy ขึ้น Vercel ได้ทันทีฟรี 100%** ในฐานะ Static Site โดยไม่ต้องเสียค่าใช้จ่ายและไม่ต้องต่อ Database ภายนอก

### 2. ถ้าต้องการให้คุณครูและนักเรียนจากหลายเครื่องแชร์คะแนนส่วนกลางแบบ Real-time (แนะนำ Database ต่อไปนี้):

| ผู้ให้บริการ Database | ประเภท | ความเหมาะสมกับ Vercel | ข้อดีเด่น | Free Tier |
| :--- | :--- | :--- | :--- | :--- |
| **🥇 Neon Serverless Postgres / Vercel Postgres** | PostgreSQL | **ดีที่สุด (Native)** | 1-Click Integration กับ Vercel, มี Connection Pooling สำหรับ Serverless ไม่เกิดปัญหา Connection เต็ม | ฟรีตลอดชีพ (0.5 GB) |
| **🥈 Supabase** | PostgreSQL + Auth + Realtime | **ยอดนิยมและใช้ง่าย** | มีหน้าจอ Dashboard จัดการตารางเหมือน Excel, มี API ในตัว, จัดการ Role ครู/นักเรียนได้ดีมาก | ฟรีตลอดชีพ (500 MB) |
| **🥉 Upstash Redis (Vercel KV)** | Key-Value / In-Memory | **เร็วที่สุดสำหรับ Leaderboard** | มีฟังก์ชัน Sorted Sets (`ZADD`, `ZRANGE`) สำหรับคำนวณและดึงอันดับ 1-3 และ Top Ranking ได้ในระดับ Millisecond | ฟรี 10,000 คำสั่ง/วัน |

### 💡 รูปแบบ Architecture ที่แนะนำเมื่อต่อ Database บน Vercel:
- สร้าง Serverless Function บน Vercel เช่น โฟลเดอร์ `/api/scores.js` และ `/api/auth.js`
- นำ Connection String ของ Database ไปใส่ไว้ใน **Vercel Project Settings -> Environment Variables (`DATABASE_URL`)**
- ผลลัพธ์: ข้อมูลความลับและรหัสผ่าน Database จะอยู่บน Cloud ฝั่ง Server 100% ไม่ถูกเปิดเผยให้นักเรียนเห็นในโค้ดหน้าเว็บอย่างแน่นอนครับ!
