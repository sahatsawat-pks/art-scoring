# 🎨 ระบบหอเกียรติยศและบันทึกคะแนนเก็บตามชิ้นงานวิชาศิลปะ (Art Classroom Management System)
### ✨ เชื่อมต่อฐานข้อมูลคลาวด์ Neon Serverless PostgreSQL พร้อมใช้งานบน Vercel

เว็บแอปพลิเคชันสำหรับบันทึกคะแนนเก็บตามชิ้นงานที่สั่งในห้องเรียนศิลปะ จัดอันดับคะแนนสะสม และบริหารจัดการห้องเรียนสำหรับนักเรียนระดับประถมศึกษา (ป.1 - ป.6) พร้อมระบบคลาวด์ฐานข้อมูล **Neon PostgreSQL**, ระบบความปลอดภัย **SHA-256 Authentication**, Favicon ไอคอน **🎨**, โพเดียม 3 มิติ และระบบนำเข้า-ส่งออก Excel/CSV ครบวงจร

---

## ☁️ สถานะการเชื่อมต่อฐานข้อมูล Neon Database

- **Host**: `ep-round-lake-b8dsdsbe-pooler.c-14.us-east-1.aws.neon.tech`
- **Database**: `neondb`
- **Engine**: PostgreSQL 18 Serverless
- **ตารางที่สร้างและ Initialized เรียบร้อยแล้ว**:
  1. `art_config` - จัดเก็บโครงสร้างระดับชั้น (ป.1 - ป.6), ห้องเรียน และหัวข้องานที่สั่ง
  2. `art_accounts` - จัดเก็บบัญชีครูผู้สอนพร้อมรหัสผ่านเข้ารหัส **SHA-256 Hash** (ไม่มี plain-text password)
  3. `art_students` - จัดเก็บข้อมูลนักเรียน เลขที่ คะแนนรายชิ้นงาน และคำติชมของครู

## 🌟 ฟังก์ชันและฟีเจอร์เด่นของระบบ

### 1. 📝 ระบบคะแนนเก็บตามงานที่สั่ง (Assignment-based Scoring)
- ประเมินคะแนนตามชิ้นงานที่สั่งจริงในห้องเรียน (ไม่มีการใส่เกรดในหน้าแรก)
- เพิ่ม / ลด / แก้ไขหัวข้องาน และกำหนดคะแนนเต็มของแต่ละงานได้อย่างอิสระผ่านปุ่ม **"📝 จัดการหัวข้องาน"**
- ทุกการแก้ไขคะแนนหรือสั่งงานใหม่จะบันทึกลงสู่ **Neon PostgreSQL บนคลาวด์ทันที** พร้อมอัปเดตตารางและโพเดียมแบบ Real-time

### 2. 🔍 นักเรียนทุกคนกดดูรายละเอียดคะแนนของตัวเองได้ (Student Portfolio Modal)
- คลิกที่ชื่อนักเรียนเพื่อดูคะแนนแต่ละชิ้นงานที่สั่ง พร้อมแถบสถานะ (✓ ส่งแล้ว / ⏳ ยังไม่ส่ง)
- แสดงคะแนนสะสมรวม, การเปรียบเทียบสถิติห้อง (เทียบกับค่าเฉลี่ยและคะแนนสูงสุด), และคำชื่นชมของคุณครู

### 3. 🔐 ระบบ Auth เข้าห้องพักครู & เพิ่ม Account ให้คุณครูท่านอื่น
- **ไม่มีการใส่ credential หรือรหัสผ่านไว้ในหน้าเว็บเด็ดขาด** (ตรวจสอบผ่าน SHA-256 Cryptographic Hash)
- เข้าสู่ระบบครั้งแรกด้วย:
  - **Username**: `admin`
  - **Password**: `admin1234`
- สามารถกดปุ่ม **"👥 เพิ่ม / จัดการ Account"** เพื่อสร้าง Username และรหัสผ่านใหม่ให้คุณครูท่านอื่นได้

### 4. 📥 📤 ระบบนำเข้า/ส่งออก Excel (.xlsx) และ CSV
- ดาวน์โหลด Template (.csv) ที่มีหัวตารางตรงตามชิ้นงานที่สั่ง ณ ขณะนั้น
- ส่งออกคะแนนทั้งห้องปัจจุบันหรือทุกห้อง เป็นไฟล์ Excel (.xlsx) และ CSV (UTF-8 BOM ภาษาไทยไม่เพี้ยน)

## 🚀 วิธีการรันใช้งาน

### วิธีที่ 1: รันในเครื่องพร้อมเชื่อมต่อ Neon Database (แนะนำ)
เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
npm start
```
หรือ
```bash
node server.js
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:3000`**
> ที่มุมบนขวาจะแสดงป้ายไฟสีเขียว: **`☁️ Neon PostgreSQL`** ยืนยันว่าระบบกำลังอ่าน-เขียนข้อมูลกับฐานข้อมูลคลาวด์จริง
